# Expense Tracker

A full-stack expense tracking web app, built solo by [Ahmed Khalid Abdallah](https://mudi-merrey.github.io).

## What it does

- **Category-based logging** — log expenses against categories for easier tracking.
- **Filterable history** — browse and filter past expenses by category and other criteria.
- **REST API backend** — a Node.js/Express API serves and stores expense data, consumed by a React frontend.

## Tech stack

`React` `Node.js` `Express`

## Architecture

A standard client-server split: the React frontend handles all UI state and calls a REST API exposed by the Express backend, which owns data persistence and validation.
